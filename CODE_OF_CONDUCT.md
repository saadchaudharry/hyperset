# Code of Conduct

## Our pledge

We want HYPERSET to be a welcoming project for everyone, whatever their experience, background, body type or fitness level.

## Expected behaviour

- Be respectful and patient, especially with newcomers.
- Give and accept constructive feedback about code, not about people.
- Assume good intent and ask questions before drawing conclusions.

## Unacceptable behaviour

- Harassment, insults, or discriminatory or demeaning comments, including body shaming.
- Personal attacks, trolling or deliberately derailing discussions.
- Publishing someone else's private information without permission.

## Enforcement

Report problems to the project maintainers by opening a private security advisory on GitHub or contacting a maintainer directly. Reports are handled confidentially. Maintainers may remove comments or contributions, or ban contributors, who break this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
